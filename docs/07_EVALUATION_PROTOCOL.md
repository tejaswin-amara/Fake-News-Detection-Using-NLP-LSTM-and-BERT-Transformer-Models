# Evaluation Protocol

## Dataset split

Default:

```text
70% training
15% validation
15% test
```

The final test set must not be used for:

- hyperparameter selection
- feature fitting
- calibration fitting
- threshold selection

## Cross-validation

Use stratified k-fold CV for model selection.

Recommended capstone configuration:

```text
5 folds
```

Use nested CV when reporting unbiased model-selection performance where practical.

## Classification metrics

Required:

- Accuracy
- Precision
- Recall
- F1
- ROC-AUC
- PR-AUC

Additional:

- confusion matrix
- class-wise support

## Calibration

Compare:

```text
raw model
vs
Platt scaling
vs
isotonic regression
```

Report:

- reliability diagram
- Brier score
- calibration behavior

## Hyperparameter search

Demonstrate at least one model-selection workflow and document the configuration.

Target methods:

- grid search
- random search
- Bayesian search

## Statistical comparison

For two paired classifiers on the same held-out observations:

- McNemar's test

Use the test only when its assumptions and pairing are appropriate.

## Required artifacts

```text
reports/
├── model_comparison.csv
├── cv_results.csv
├── classification_metrics.json
├── calibration_results.json
├── confusion_matrix.png
├── roc_curve.png
├── pr_curve.png
└── calibration_curve.png
```

## Truthfulness rule

Never write or display a benchmark value unless it was generated by an executed experiment. Missing hardware, data, or optional dependencies shall result in an explicit "unavailable" status.
