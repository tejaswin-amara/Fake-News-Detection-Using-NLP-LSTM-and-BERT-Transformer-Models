# Code of Conduct

## Our commitment

We are committed to a respectful, constructive, and inclusive collaboration space. Participants in repository discussions, issues, pull requests, reviews, and other project interactions are expected to engage in good faith and to treat others with professional consideration.

## Expected behavior

Contributors should communicate respectfully, welcome evidence-based disagreement, give useful review feedback, acknowledge uncertainty, and protect private information. Technical claims should be reproducible and should distinguish observed results from proposals or assumptions.

## Unacceptable behavior

Harassment, discriminatory language, threats, personal attacks, deliberate disclosure of private information, malicious security testing against others, plagiarism, and knowingly fabricated technical or performance claims are unacceptable. Do not use the project to target individuals or groups with harmful misinformation.

## Scope and enforcement

This Code applies to interactions in project-controlled spaces and to project-related conduct that materially affects the collaboration environment. Maintainers may request clarification, edit or remove content, reject contributions, temporarily limit participation, or permanently remove access when necessary to protect the community and the repository.

## Reporting

Do not post sensitive personal information or exploit details in a public issue. Security vulnerabilities must be reported through the repository’s GitHub-native private **Report a vulnerability** flow as described in [`SECURITY.md`](SECURITY.md). For non-security conduct concerns, use GitHub’s repository communication tools to request maintainer review and include only the minimum information needed for a fair assessment. This repository intentionally does not publish a separate support or security email address.

## References

This project-specific policy operates with the contributor workflow in [`CONTRIBUTING.md`](CONTRIBUTING.md) and the security process in [`SECURITY.md`](SECURITY.md).
