CO1 · Vectorization NLTK / Scikit-Learn

Sublinear TF-IDF with Smooth IDF

Dampens document length bias and suppresses high-frequency lexical artifacts:

$$\text{tf-idf}(t, d, D) = (1 + \ln \text{tf}(t, d)) \times \left( \ln \frac{1 + |D|}{1 + \text{df}(t, D)} + 1 \right)$$
Followed by Euclidean norm normalization: \(\|\mathbf{x}\|_2 = 1\).
CO2 · Convex Optimization L1 / L2 / ElasticNet

Penalized Negative Log-Likelihood

Enforces sparsity (L1) or controls Frobenius norm (L2) to prevent overfitting:

$$\min_{\mathbf{w}, b} -\frac{1}{N}\sum_{i=1}^N \left[ y_i \ln \sigma_i + (1 - y_i)\ln(1 - \sigma_i) \right] + \frac{\lambda_1}{\|\mathbf{w}\|_1} + \frac{\lambda_2}{2}\|\mathbf{w}\|_2^2$$
Sigmoid link: \(\sigma_i = \sigma(\mathbf{w}^T \mathbf{x}_i + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x}_i + b)}}\).
CO3 · Non-Linear Trees CART / Pruning

Gini Impurity & Cost-Complexity

Optimal partition selection with minimal cost-complexity regularization:

$$I_G(t) = 1 - \sum_{k=1}^K p_{tk}^2, \quad R_\alpha(T) = R(T) + \alpha |T|$$
Information gain: \(\Delta I = I(D) - \frac{|D_L|}{|D|}I(D_L) - \frac{|D_R|}{|D|}I(D_R)\).
CO4 · Deep Transformers BERT-base-uncased

Scaled Dot-Product Attention

Contextualized token interaction across 12 attention heads and 768 hidden dimensions:

$$\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{QK^T}{\sqrt{d_k}} \right) V$$
Multi-head projection: \(\text{MHA}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W^O\).
CO6 · Calibration Platt Scaling

Platt Scaling & Brier Loss

Post-hoc sigmoid transformation mapping margins to true empirical posterior probabilities:

$$P(y=1|f) = \frac{1}{1 + \exp(Af + B)}, \quad \text{Brier} = \frac{1}{N}\sum_{i=1}^N (p_i - y_i)^2$$
Fitted strictly on validation split to guarantee zero held-out test contamination.
CO6 · Drift SRE KS-Test & PSI

Kolmogorov-Smirnov & PSI

Non-parametric distribution comparison detecting concept drift in real-time inference streams:

$$D_{KS} = \sup_x |F_1(x) - F_2(x)|, \quad \text{PSI} = \sum_{b=1}^B (A_b - E_b) \ln \frac{A_b}{E_b}$$
Operational boundary: \(\text{PSI} < 0.1\) (Stable), \(\ge 0.2\) (Retrain Action).
